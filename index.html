Ce que MIENRA permet de faire

Cette page est une version de démonstration web. La version complète du projet reste une application desktop Electron 100 % offline avec base de données locale.

1

Suivre les inscriptions

Enregistrer les élèves, classes, années scolaires et montants attendus.

2

Gérer les paiements

Suivre les versements, soldes restants, reçus et historiques.

3

Voir les impayés

Identifier rapidement les élèves ou classes avec des soldes à régulariser.

4

Produire des rapports

Préparer des synthèses financières utiles pour la direction de l’école.

5

Fonctionner hors ligne

La version complète est pensée pour fonctionner même sans connexion Internet.

6

Sécuriser les accès

Prévoir des rôles : administrateur, directeur, secrétaire ou comptable.

Démo interactive simplifiée

Clique sur un module pour afficher un exemple d’écran.

Note : cette démo web ne remplace pas la version complète. Elle sert à présenter l’idée aux écoles et à tester l’interface depuis GitHub Pages.
